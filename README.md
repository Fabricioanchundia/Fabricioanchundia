## 🚀 Featured Projects

### 🔐 [Ninca](https://github.com/Fabricioanchundia/IA-NINCA) — Security scanner for MCP servers

Scans Model Context Protocol servers for hidden malicious instructions, excessive permissions and exposed secrets.

- Analyzed **33,477 public MCP servers** and published *The State of MCP Server Security 2026*
- Hybrid rules + local LLM: recall **57% → 86%** with **100% precision**
- Works as a CLI, a **GitHub Action** (CI gate) and a live guard that blocks risky servers

`Python` `DuckDB` `Ollama` `GitHub Actions` `Docker`

### 🏛️ [Lupa Pública](https://github.com/Fabricioanchundia/IA-Lupa-publica) — AI transparency for Ecuador's public procurement

Open-data platform that flags spending risk signals in government contracts.

- **343,078 procurement processes** (~US$13B), refreshed automatically every month
- Ask in Spanish: **Text-to-SQL** with a local LLM (17/18 on eval) + **RAG over procurement law** with verified citations
- Read-only **MCP server** so any AI agent can query the data safely

`Python` `dbt` `DuckDB` `React` `TypeScript` `Ollama` `MCP`

### 💳 [Halcón](https://github.com/Fabricioanchundia/IA-Halcon) — Real-time payment fraud detection

Simulated payments platform with a fraud model, an AI analyst agent and SRE-grade monitoring.

- Cut fraud losses by **~90%** vs. approve-all in a 30-day test (PR-AUC 0.90)
- **2,000+ transactions/s** with ~10 ms p50 latency
- Red-team and concept-drift experiments with documented results

`Python` `Machine Learning` `Docker` `Ollama`

### 🍯 [Panal](https://github.com/Fabricioanchundia/IA-PANAL) — Cloud honeypot + AI SOC analyst *(in progress 🚧)*

A honeypot receives real internet attacks, and an AI agent classifies them and maps them to **MITRE ATT&CK**.

`Python` `Cowrie` `AWS` `Terraform` `Docker`
